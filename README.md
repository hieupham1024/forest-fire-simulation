# forest-fire-simulation
## Description

This project is a forest fire simulation written in Rust. It demonstrates emergent behavior by showing how simple rules can create complex patterns in a forest.

## Features (Planned)

- Simulate tree growth and fire spreading.
- Display the forest using a terminal-based grid.
- Allow users to change simulation settings.
- Track the number of living trees, burning trees, and empty cells.

## Technologies

- Rust
- Cargo
